# Engineering rules
Architecture: FastAPI in services/api, React in apps/web, SQLite in data. Public API is versioned under /api/v1. Use snake_case in Python and camelCase in TypeScript. Web calls API with credentials; configure Vite proxy for development. Migrate schema deliberately and preserve existing data; never casually replace working architecture. Preserve public API compatibility unless versioned. Isolate user and application data in every query. Never expose secrets or chain-of-thought. Do not bypass authorization, invent APIs, execute model-generated shell or SQL, or put secrets in source. UI may show short tool status, never hidden reasoning. Run pytest, npm test and npm build before completion; update docs/BUILD_STATE.md after substantial changes. Keep dependencies pinned and review updates. Commands: `python -m uvicorn services.api.main:app --reload`; `cd apps/web && npm run dev`; `python -m pytest tests`; `cd apps/web && npm test && npm run build`.

Release guidance: Run `./scripts/test.sh` (or PowerShell equivalent), `npm run lint`, and Python Ruff F checks. Document E2E browser availability honestly. Keep `docs/RELEASE_CHECKLIST.md`, `docs/ROADMAP.md` and `docs/BUILD_STATE.md` consistent. Treat Ollama output, uploaded content, and user-authored memories as untrusted. Do not claim verified AI correctness from mocked provider tests. Do not expose a public deployment before the blockers in `docs/SECURITY.md` are resolved.


## First Comet learner principle
First Comet exists to make coding and software creation understandable to complete beginners, including a 15-year-old opening developer tools for the first time. Prefer one clear next action, progressive disclosure, plain language, and real project outcomes over documentation walls. Learner-facing progression should use Stage → Path → Step → Checkpoint/Title language rather than Course/Lesson wording. Every major learning stage should connect to something the learner actually creates: a local page, an interactive project, a GitHub repository, connected data, or a live deployment. Progress titles describe First Comet completion only and must never be presented as professional credentials. Keep optional tools, offers, and advanced theory out of the core journey unless they are needed for the learner's current build.
