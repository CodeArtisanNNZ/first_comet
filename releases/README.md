# First Comet releases

## Web Preview v1.0.0 — 17 September 2026

This is the first public preview of the new First Comet visual direction.

### Included

- New First Comet brand and comic-style logo
- Animated Anime.js introduction
- Responsive launchpad and project studio
- Project creation stored locally in the browser
- Guided build workflow
- Pocket learning reference
- Light and dark themes
- Keyboard command palette

### Download

Download `First-Comet-Web-Preview-v1.0.0.zip` from this folder, extract it and open `index.html`.

### Limitation

The preview demonstrates the interface and guided workflow. Browser security prevents direct unrestricted access to local project folders and Git credentials. Those capabilities remain part of the desktop migration.
